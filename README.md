# Stranger Things
**Stranger Things** is one of my favorite series! 
It’s a *sci-fi horror drama* created by the Duffer Brothers and released on **Netflix**.

## Main Characters
**Eleven (Millie Bobby Brown)** – a girl with telekinetic abilities  
**Mike Wheeler (Finn Wolfhard)** – Eleven’s close friend  
**Dustin Henderson (Gaten Matarazzo)** – the funny and smart one  
**Lucas Sinclair (Caleb McLaughlin)** – loyal and brave  
**Will Byers (Noah Schnapp)** – the boy who first disappears  
**Jim Hopper (David Harbour)** – the town’s police chief  

*“Friends don’t lie.”*
